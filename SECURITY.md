# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub's **Security** tab and choose **Report a vulnerability** to submit details privately. Include the affected area, reproduction steps, impact, and any suggested mitigation.

You can expect an acknowledgement within 7 days. Please allow time for a fix before public disclosure.

## Supported version

Only the latest version on the default branch is supported.
